Workflow

End-to-End Pipeline

Two Colab notebooks cover the full lifecycle — from raw Kaggle data to an explainable, annotated output.

01 / TRAINING
Environment Setup
Install Ultralytics, Supervision, PyTorch. Verify T4 GPU. Mount Google Drive.
02 / TRAINING
Dataset Prep
Download PPE Clean Dataset from Kaggle. Filter 4 PPE classes. Remap label IDs.
03 / TRAINING
Train RT-DETRv4-X
AdamW + cosine LR + FP16. 15 epochs, 640px. Checkpoints saved to Drive.
04 / TRAINING
Evaluate
mAP, per-class AP, precision, recall, F1, MCC. FPS benchmark on T4 GPU.
05 / TESTING
Video & Image Inference
Custom images + video. Annotated outputs with colour-coded bounding boxes.
06 / TESTING
Explainable AI
EigenCAM heatmaps per class — visualises where the model looks to decide.

Why EigenCAM matters

Deep learning models are often treated as black boxes. EigenCAM makes the decisions transparent by showing the spatial regions the model's convolutional backbone activates on. For a safety-critical system like PPE detection, this interpretability layer is essential — it validates the model isn't relying on spurious correlations (e.g. background colour) but genuinely attends to helmet and vest regions.

Tech Stack

Tools & Libraries

Every component was chosen for speed, reproducibility, and state-of-the-art performance.

🤗
RT-DETRv4-X
Primary Model
Real-Time DEtection TRansformer (X-large variant). Combines transformer attention with CNN backbone for high-accuracy real-time detection without NMS overhead.
🔥
PyTorch
Deep Learning Framework
FP16 mixed precision (AMP), AdamW optimiser, cosine LR scheduling, 3-epoch warmup, and early stopping. Runs on CUDA T4 GPU.
⚡
Ultralytics
Training API
High-level wrapper used for model.train(), model.val(), model.predict(). Handles YAML config, checkpointing, and results.csv logging automatically.
👁️
Supervision
Annotation Utilities
Bounding box drawing, label rendering, and colour-coded annotations on images and video frames.
🌡️
EigenCAM
Explainable AI (XAI)
Grad-CAM variant applied via pytorch-grad-cam. Produces per-class heat maps showing which image regions drive each detection decision.
🏗️
Google Colab
Training Environment
NVIDIA T4 GPU runtime. Models and outputs persisted to Google Drive. kaggle.json for dataset download via Kaggle API.
📦
OpenCV
Video Processing
Frame-by-frame inference on input video. BGR → RGB conversion, bounding box rendering, and H.264 mp4 export.
📐
scikit-learn
Evaluation Metrics
Per-class Precision, Recall, F1, MCC, and confusion matrix computed from inference results on the held-out test split.
