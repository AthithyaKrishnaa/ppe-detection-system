# PPE Detection System with Explainable AI for Industrial Safety

## Dataset Structure

The dataset for this project is structured as follows:

```yaml
path: /content/dataset
train: train/images
val: valid/images
test: test/images

nc: 4
names:
  - Helmet
  - No Helmet
  - Safety Vest
  - No Safety Vest
```
